# Rust Language Features

This crate contains code examples covering fundamental Rust language features, syntax, ownership rules, types, pattern matching, macros, and core control structures.

## Examples Covered

- **Basic Concepts**: Variables, mutability, data types, function signatures, and control flow (`if`, `loop`, `while`, `for`).
- **Ownership & Borrowing**: References, borrowing rules, move semantics, and slices.
- **Structs & Enums**: Defining structures, method syntax (`impl`), enumerations, and pattern matching (`match`, `if let`).
- **Generics & Traits**: Trait definitions, generic bounds, trait objects (`dyn`), and associated types.
- **Macros & Pragmas**: Declarative macros (`macro_rules!`) and language attributes.

## Usage

To check or run examples in this crate:

```console
cargo check --package language --examples
cargo test --package language
```

Code examples correspond to chapters in `bk/src/language/`.
