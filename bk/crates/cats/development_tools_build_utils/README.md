# Development Tools Build Utils

This crate contains code examples for the **Development Tools Build Utils** category on crates.io. It demonstrates integration with key ecosystem crates including `anyhow`, `autocfg`, `build-info`, `cc`, `clap`, `tracing`.

## Examples Covered

- **Autocfg** (`examples/autocfg/`): Demonstrates concepts like `autocfg`.
- **Build Info** (`examples/build_info/`): Demonstrates concepts like `build_info`.
- **Build Time Tooling** (`examples/build_time_tooling/`): Demonstrates concepts like `c_library`, `cc_bundled_cpp`, `cc_bundled_cpp1`, `cc_bundled_static`, `cc_bundled_static1`, `cc_defines`, `cc_defines1`, `cpp_library`, `out_dir_codegen`.

## Usage

To check or run examples in this crate:

```console
cargo check --package development_tools_build_utils --examples
cargo test --package development_tools_build_utils
```

Code examples correspond to chapters in `bk/src/categories/development_tools_build_utils` or related book sections.
