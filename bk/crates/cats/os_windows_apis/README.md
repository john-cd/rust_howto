# OS Windows APIS

This crate contains code examples for the **OS Windows APIS** category on crates.io. It demonstrates integration with key ecosystem crates including `clap`.

## Examples Covered

- **Windows** (`examples/windows/`): Demonstrates concepts like `winapi`, `windows`.

## Usage

To check or run examples in this crate:

```console
cargo check --package os_windows_apis --examples
cargo test --package os_windows_apis
```

Code examples correspond to chapters in `bk/src/categories/os_windows_apis` or related book sections.
