# Template Engine

Code examples for popular Rust template engines including Tera and TinyTemplate. It demonstrates integration with key ecosystem crates including `anyhow`, `serde`, `tera`, `tinytemplate`.

## Examples Covered

- **Tera** (`examples/tera/`): Demonstrates concepts like `tera`.
- **Tinytemplate** (`examples/tinytemplate/`): Demonstrates concepts like `tinytemplate`.

## Usage

To check or run examples in this crate:

```console
cargo check --package template_engine --examples
cargo test --package template_engine
```

Code examples correspond to chapters in `bk/src/categories/template_engine` or related book sections.
