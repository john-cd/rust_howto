# Parser Implementations

This crate contains code examples for the **Parser Implementations** category on crates.io. It demonstrates integration with key ecosystem crates including `anyhow`, `chrono`, `clap`, `comrak`, `configparser`, `cssparser`.

## Examples Covered

- **Html** (`examples/html/`): Demonstrates concepts like `cssparser`, `html5ever`, `scraper`, `tl`.
- **Ini** (`examples/ini/`): Demonstrates concepts like `configparser_ini`, `rust_ini`.
- **Javascript** (`examples/javascript/`): Demonstrates concepts like `swc_ecma_parser`.
- **Json** (`examples/json/`): Demonstrates concepts like `json5`, `serde_json`, `simd_json`.
- **Markdown** (`examples/markdown/`): Demonstrates concepts like `comrak`, `markdown`, `pulldown_cmark`.
- **Programming Languages** (`examples/programming_languages/`): Demonstrates concepts like `sql_readonly`, `sqlparser`, `syn`.
- **Toml** (`examples/toml/`): Demonstrates concepts like `basic_toml`, `toml`, `toml_edit`.
- **Xml** (`examples/xml/`): Demonstrates concepts like `quick_xml`, `roxmltree`, `xml`, `xml5ever`, `xmlparser`.
- **Yaml** (`examples/yaml/`): Demonstrates concepts like `serde_saphyr`.

## Usage

To check or run examples in this crate:

```console
cargo check --package parser_implementations --examples
cargo test --package parser_implementations
```

Code examples correspond to chapters in `bk/src/categories/parser_implementations` or related book sections.
