# Config

This crate contains code examples for the **Config** category on crates.io. It demonstrates integration with key ecosystem crates including `anyhow`, `clap`, `config`, `confy`, `dotenvy`, `envy`.

## Examples Covered

- **Configuration** (`examples/configuration/`): Demonstrates concepts like `config_singleton`, `config_testing`, `confy`.
- **Env** (`examples/env/`): Demonstrates concepts like `dotenvy`, `env`, `envy`.

## Usage

To check or run examples in this crate:

```console
cargo check --package config --examples
cargo test --package config
```

Code examples correspond to chapters in `bk/src/categories/config` or related book sections.
