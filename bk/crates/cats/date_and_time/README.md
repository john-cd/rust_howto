# Date and Time

This crate contains code examples for the **Date and Time** category on crates.io. It demonstrates integration with key ecosystem crates including `anyhow`, `chrono`, `clap`, `humantime`, `time`.

## Examples Covered

- **Chrono** (`examples/chrono/`): Demonstrates concepts like `checked`, `current`, `format`, `parse_string_into_datetime`, `timestamp`, `timezone`.
- **Duration** (`examples/duration/`): Demonstrates concepts like `profile`.
- **Standalone Examples**: `humantime`, `time`.

## Usage

To check or run examples in this crate:

```console
cargo check --package date_and_time --examples
cargo test --package date_and_time
```

Code examples correspond to chapters in `bk/src/categories/date_and_time` or related book sections.
