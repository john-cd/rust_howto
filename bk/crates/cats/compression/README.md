# Compression

Book code examples - compression It demonstrates integration with key ecosystem crates including `anyhow`, `async-compression`, `async_zip`, `clap`, `flate2`, `futures-lite`.

## Examples Covered

- **Compression** (`examples/compression/`): Demonstrates concepts like `async_compression`, `async_zip`, `flate2`, `zip`.
- **Tar** (`examples/tar/`): Demonstrates concepts like `tar_compress`, `tar_decompress`, `tar_strip_prefix`.

## Usage

To check or run examples in this crate:

```console
cargo check --package compression --examples
cargo test --package compression
```

Code examples correspond to chapters in `bk/src/categories/compression` or related book sections.
