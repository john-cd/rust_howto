# Caching

This crate contains code examples for the **Caching** category on crates.io. It demonstrates integration with key ecosystem crates including `cached`, `clap`, `lru`, `moka`.

## Examples Covered

- **In Memory Cache** (`examples/in_memory_cache/`): Demonstrates concepts like `cached`, `lru`, `moka`.

## Usage

To check or run examples in this crate:

```console
cargo check --package caching --examples
cargo test --package caching
```

Code examples correspond to chapters in `bk/src/categories/caching` or related book sections.
