# Text Processing

This crate contains code examples for the **Text Processing** category on crates.io. It demonstrates integration with key ecosystem crates including `aho-corasick`, `anyhow`, `bstr`, `clap`, `concat-string`, `console`.

## Examples Covered

- **Diffing** (`examples/diffing/`): Demonstrates concepts like `diff`, `similar`.
- **Other Strings** (`examples/other_strings/`): Demonstrates concepts like `bstr`, `cstring`, `osstring`, `ustr`.
- **Regex** (`examples/regex/`): Demonstrates concepts like `email`, `fancy_regex`, `filter_log`, `hashtags`, `phone`, `regex`, `replace`.
- **String Concat** (`examples/string_concat/`): Demonstrates concepts like `string_concat`, `string_concat2`.
- **String Manipulation** (`examples/string_manipulation/`): Demonstrates concepts like `case_conversion`, `heck`, `indoc`, `slug`, `textwrap`.
- **String Parsing** (`examples/string_parsing/`): Demonstrates concepts like `from_str`.
- **String Search** (`examples/string_search/`): Demonstrates concepts like `aho_corasick`, `aho_corasick_redact`, `fuzzy_matcher`, `memchr`, `strsim`.
- **Text Analysis** (`examples/text_analysis/`): Demonstrates concepts like `fuzzy_search`, `keyword_extraction`, `syntect_html`, `tree_sitter_json_spans`, `word_boundaries`.
- **Unicode** (`examples/unicode/`): Demonstrates concepts like `graphemes`.

## Usage

To check or run examples in this crate:

```console
cargo check --package text_processing --examples
cargo test --package text_processing
```

Code examples correspond to chapters in `bk/src/categories/text_processing` or related book sections.
