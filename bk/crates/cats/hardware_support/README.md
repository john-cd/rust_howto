# Hardware Support

This crate contains code examples for the **Hardware Support** category on crates.io. It demonstrates integration with key ecosystem crates including `clap`, `num_cpus`, `wide`.

## Examples Covered

- **Processor** (`examples/processor/`): Demonstrates concepts like `cpu_count`.
- **Simd** (`examples/simd/`): Demonstrates concepts like `simd_arch`.

## Usage

To check or run examples in this crate:

```console
cargo check --package hardware_support --examples
cargo test --package hardware_support
```

Code examples correspond to chapters in `bk/src/categories/hardware_support` or related book sections.
