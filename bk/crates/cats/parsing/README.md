# Parsing

This crate contains code examples for the **Parsing** category on crates.io. It demonstrates integration with key ecosystem crates including `anyhow`, `clap`, `nom`, `pest`, `pest_derive`, `tree-sitter`.

## Examples Covered

- **Calc** (`examples/calc/`): Demonstrates concepts like `calc_parser`.
- **Parsing** (`examples/parsing/`): Demonstrates concepts like `nom`, `tree_sitter`, `tree_sitter_spans`, `winnow`.
- **Pest** (`examples/pest/`): Demonstrates concepts like `pest`.

## Usage

To check or run examples in this crate:

```console
cargo check --package parsing --examples
cargo test --package parsing
```

Code examples correspond to chapters in `bk/src/categories/parsing` or related book sections.
