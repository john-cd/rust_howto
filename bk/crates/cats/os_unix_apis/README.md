# OS Unix APIS

This crate contains code examples for the **OS Unix APIS** category on crates.io. It demonstrates integration with key ecosystem crates including `anyhow`, `clap`.

## Examples Covered

- **Unix** (`examples/unix/`): Demonstrates concepts like `nix`, `rustix`.

## Usage

To check or run examples in this crate:

```console
cargo check --package os_unix_apis --examples
cargo test --package os_unix_apis
```

Code examples correspond to chapters in `bk/src/categories/os_unix_apis` or related book sections.
