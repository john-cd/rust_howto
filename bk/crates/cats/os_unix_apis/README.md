# OS Unix APIS

This crate contains examples used by the book's **Unix APIs** category. It demonstrates Unix-specific interfaces with the `nix` and `rustix` crates.

## Examples Covered

- **Unix** (`examples/unix/`): Demonstrates concepts like `nix`, `rustix`.

## Usage

To check or run examples in this crate:

```console
cargo check --package os_unix_apis --examples
cargo test --package os_unix_apis
```

Code examples correspond to chapters in `bk/src/categories/os_unix-apis` or related book sections.
