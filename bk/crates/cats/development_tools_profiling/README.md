# Development Tools Profiling

This crate contains code examples for the **Development Tools Profiling** category on crates.io. It demonstrates integration with key ecosystem crates including `criterion`, `dhat`, `measure_time`, `profiling`, `puffin`, `puffin_http`.

## Examples Covered

- **Benchmarking** (`examples/benchmarking/`): Demonstrates concepts like `criterion`.
- **Standalone Examples**: `dhat_assertions`, `profiling_scopes`, `puffin_server`.

## Usage

To check or run examples in this crate:

```console
cargo check --package development_tools_profiling --examples
cargo test --package development_tools_profiling
```

Code examples correspond to chapters in `bk/src/categories/development_tools_profiling` or related book sections.
