# About & Introduction

This crate contains beginner-friendly code examples from the introduction section of the book, demonstrating foundational Rust concepts like simple interactive CLI programs and language introductory snippets.

## Examples Covered

- **Guessing Game**: An interactive command-line guessing game demonstrating user input, number parsing, random number generation (`rand`), and control flow.
- **Introduction**: Basic syntax, hello-world, and overview snippets.

## Usage

To check or run examples in this crate:

```console
cargo check --package about --examples
cargo test --package about
cargo run --package about --example guessing_game
```

Code examples correspond to chapters in `bk/src/about/`.
