# Localize API Errors

{{#include i18n.incl.md}}

An API can use the `Accept-Language` request header to choose a supported translation for an error. The example keeps the `rust_i18n::i18n!` macro at the root of its own binary crate, loads English and French YAML catalogs, and falls back to English when the header has no supported language.
