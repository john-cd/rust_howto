# Aerospace

This crate contains code examples for the **Aerospace** category on crates.io. It demonstrates integration with key ecosystem crates including `sgp4`.

## Examples Covered

- **Aerospace** (`examples/aerospace/`): Demonstrates concepts like `aero`.

## Usage

To check or run examples in this crate:

```console
cargo check --package aerospace --examples
cargo test --package aerospace
```

Code examples correspond to chapters in `bk/src/categories/aerospace` or related book sections.
