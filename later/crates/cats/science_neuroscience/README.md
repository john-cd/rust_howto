# Science Neuroscience

This crate contains code examples for the **Science Neuroscience** category on crates.io. It demonstrates integration with key ecosystem crates including `ndarray`, `nifti`.

## Examples Covered

- **Neuroscience** (`examples/neuroscience/`): Demonstrates concepts like `leaky_integrate_fire`, `neuro`.

## Usage

To check or run examples in this crate:

```console
cargo check --package science_neuroscience --examples
cargo test --package science_neuroscience
```

Code examples correspond to chapters in `bk/src/categories/science_neuroscience` or related book sections.
