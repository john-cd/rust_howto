# Science Neuroscience

This crate contains code examples for the staged **Science - Biology and Neuroscience** category. It demonstrates integration with key ecosystem crates including `ndarray`, `nifti`, and `rustfft`.

## Examples Covered

- **Neuroscience** (`examples/neuroscience/`): Demonstrates a leaky integrate-and-fire model, synthetic NIfTI volume writing, and frequency analysis of a synthetic signal.

## Usage

To check or run examples in this crate:

```console
cargo check --package science_neuroscience --examples
cargo test --package science_neuroscience
```

Code examples correspond to staged chapters in `later/src/categories/science_neuroscience` or related book sections.
