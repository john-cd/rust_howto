# Aerospace Space Protocols

This crate contains code examples for the **Aerospace Space Protocols** category on crates.io. It demonstrates integration with key ecosystem crates including `arbitrary-int`, `spacepackets`.

## Examples Covered

- **Space Protocols** (`examples/space_protocols/`): Demonstrates concepts like `pus_telecommand`, `pus_telemetry`, `space_protocols`.

## Usage

To check or run examples in this crate:

```console
cargo check --package aerospace_space_protocols --examples
cargo test --package aerospace_space_protocols
```

Code examples correspond to chapters in `bk/src/categories/aerospace_space_protocols` or related book sections.
