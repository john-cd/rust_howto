# No Std No Alloc

This crate contains code examples for the **No Std No Alloc** category on crates.io. It demonstrates integration with key ecosystem crates including `heapless`.

## Examples Covered

- **No Alloc** (`examples/no_alloc/`): Demonstrates concepts like `no_alloc`.

## Usage

To check or run examples in this crate:

```console
cargo check --package no_std_no_alloc --examples
cargo test --package no_std_no_alloc
```

Code examples correspond to chapters in `bk/src/categories/no_std_no_alloc` or related book sections.
