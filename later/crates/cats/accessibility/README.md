# Accessibility

Book code examples for Accessibility using AccessKit and Winit. It demonstrates integration with key ecosystem crates including `accesskit`, `accesskit_winit`, `winit`.

## Examples Covered

- **Screen Readers** (`examples/screen_readers/`): Demonstrates concepts like `accesskit`.

## Usage

To check or run examples in this crate:

```console
cargo check --package accessibility --examples
cargo test --package accessibility
```

Code examples correspond to chapters in `bk/src/categories/accessibility` or related book sections.
