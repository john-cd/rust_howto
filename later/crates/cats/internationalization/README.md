# Internationalization

This crate contains code examples for the **Internationalization** category on crates.io. It demonstrates integration with key ecosystem crates including `icu`.

## Examples Covered

- **Internationalization** (`examples/internationalization/`): Demonstrates concepts like `icu_formatting`.

## Usage

To check or run examples in this crate:

```console
cargo check --package internationalization --examples
cargo test --package internationalization
```

Code examples correspond to chapters in `bk/src/categories/internationalization` or related book sections.
