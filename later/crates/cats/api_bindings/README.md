# API Bindings

This crate contains code examples for the **API Bindings** category on crates.io.

## Examples Covered

- **API Bindings** (`examples/api_bindings/`): Code examples covering api bindings.

## Usage

To check or run examples in this crate:

```console
cargo check --package api_bindings --examples
cargo test --package api_bindings
```

Code examples correspond to chapters in `bk/src/categories/api_bindings` or related book sections.
