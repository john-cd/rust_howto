# OS Freebsd APIS

This crate contains code examples for the **OS Freebsd APIS** category on crates.io.

## Examples Covered

- **Freebsd** (`examples/freebsd/`): Demonstrates concepts like `freebsd`.

## Usage

To check or run examples in this crate:

```console
cargo check --package os_freebsd_apis --examples
cargo test --package os_freebsd_apis
```

Code examples correspond to chapters in `bk/src/categories/os_freebsd_apis` or related book sections.
