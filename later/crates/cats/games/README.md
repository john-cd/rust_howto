# README

Code examples are found under `examples/<chapter_name>`, where `<chapter_name>` is the name of the `.md` file in `bk/<...>/categories/<category_name>` that includes these examples.

Run the staged Macroquad example from `later/crates`:

```console
cargo run --locked -p games --example games
```

The window displays a rotating triangle; press Space to change its color.
