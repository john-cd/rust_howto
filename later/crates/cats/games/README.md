# Games

This crate contains code examples for the **Games** category on crates.io. It demonstrates integration with key ecosystem crates including `macroquad`.

## Examples Covered

- **Standalone Examples**: `games`.

## Usage

To check or run examples in this crate:

```console
cargo check --package games --examples
cargo test --package games
```

Code examples correspond to chapters in `bk/src/categories/games` or related book sections.

Run the staged Macroquad example from `later/crates`:

```console
cargo run --locked -p games --example games
```

The window displays a rotating triangle; press Space to change its color.
