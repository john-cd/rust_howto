# Finance

This crate contains code examples for the **Finance** category on crates.io. It demonstrates integration with key ecosystem crates including `anyhow`, `black_scholes`, `chrono`, `governor`, `serde_json`, `ta-statistics`.

## Examples Covered

- **Market Data** (`examples/market_data/`): Demonstrates concepts like `yahoo_history`.
- **Quant** (`examples/quant/`): Demonstrates concepts like `black_scholes`, `rolling_stats`, `rustquant`, `trading_days`.

## Usage

To check or run examples in this crate:

```console
cargo check --package finance --examples
cargo test --package finance
```

Code examples correspond to chapters in `bk/src/categories/finance` or related book sections.
