# VIZIA

This crate contains code examples for the **VIZIA** category on crates.io. It demonstrates integration with key ecosystem crates including `vizia`.

## Examples Covered

- **Core Examples**: Code modules in `src/` or `tests/` demonstrating category functionality.

## Usage

To check or run examples in this crate:

```console
cargo check --package gui_vizia --examples
cargo test --package gui_vizia
```

Code examples correspond to chapters in `bk/src/categories/vizia` or related book sections.
