# Computer Vision

This crate contains code examples for the **Computer Vision** category on crates.io.

## Examples Covered

- **Opencv** (`examples/opencv/`): Demonstrates concepts like `opencv`.

## Usage

To check or run examples in this crate:

```console
cargo check --package computer_vision --examples
cargo test --package computer_vision
```

Code examples correspond to chapters in `bk/src/categories/computer_vision` or related book sections.
