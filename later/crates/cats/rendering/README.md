# Rendering

This crate contains code examples for the **Rendering** category on crates.io. It demonstrates integration with key ecosystem crates including `resvg`, `usvg`.

## Examples Covered

- **2d Raster Graphics** (`examples/2d_raster_graphics/`): Demonstrates concepts like `tiny_skia`.
- **2d Vector Graphics** (`examples/2d_vector_graphics/`): Code examples covering 2d vector graphics.
- **3d Renderers** (`examples/3d_renderers/`): Code examples covering 3d renderers.
- **Svg Rendering** (`examples/svg_rendering/`): Demonstrates concepts like `resvg`, `usvg`.
- **Text Rendering** (`examples/text_rendering/`): Code examples covering text rendering.

## Usage

To check or run examples in this crate:

```console
cargo check --package rendering --examples
cargo test --package rendering
```

Code examples correspond to chapters in `bk/src/categories/rendering` or related book sections.
