# Aerospace Unmanned Aerial Vehicles

This crate contains code examples for the **Aerospace Unmanned Aerial Vehicles** category on crates.io. It demonstrates integration with key ecosystem crates including `tello`.

## Examples Covered

- **UAVS** (`examples/uavs/`): Demonstrates concepts like `uavs`.

## Usage

To check or run examples in this crate:

```console
cargo check --package aerospace_unmanned_aerial_vehicles --examples
cargo test --package aerospace_unmanned_aerial_vehicles
```

Code examples correspond to chapters in `bk/src/categories/aerospace_unmanned_aerial_vehicles` or related book sections.
