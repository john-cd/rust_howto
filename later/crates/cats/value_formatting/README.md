# Value Formatting

This crate contains code examples for the **Value Formatting** category on crates.io. It demonstrates integration with key ecosystem crates including `heck`, `humansize`, `itoa`, `num-format`, `ryu`.

## Examples Covered

- **Case Conversion** (`examples/case_conversion/`): Demonstrates concepts like `case_conversion`.
- **Number Formatting** (`examples/number_formatting/`): Demonstrates concepts like `humansize_example`, `itoa`, `ryu`, `standard_and_localized`.

## Usage

To check or run examples in this crate:

```console
cargo check --package value_formatting --examples
cargo test --package value_formatting
```

Code examples correspond to chapters in `bk/src/categories/value_formatting` or related book sections.
