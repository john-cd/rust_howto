# OS Macos APIS

This crate contains code examples for the **OS Macos APIS** category on crates.io.

## Examples Covered

- **Macos** (`examples/macos/`): Demonstrates concepts like `macos`.

## Usage

To check or run examples in this crate:

```console
cargo check --package os_macos_apis --examples
cargo test --package os_macos_apis
```

Code examples correspond to chapters in `bk/src/categories/os_macos_apis` or related book sections.
