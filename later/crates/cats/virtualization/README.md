# Virtualization

This crate contains code examples for the **Virtualization** category on crates.io. It demonstrates integration with key ecosystem crates including `wasmi`.

## Examples Covered

- **Virtualization** (`examples/virtualization/`): Demonstrates concepts like `virtualization1`.

## Usage

To check or run examples in this crate:

```console
cargo check --package virtualization --examples
cargo test --package virtualization
```

Code examples correspond to chapters in `bk/src/categories/virtualization` or related book sections.
