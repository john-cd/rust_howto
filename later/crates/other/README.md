# Staged Cloud Examples

This package contains the Kubernetes operator and the historical Shuttle example. To check the cloud examples from `later/crates`, run:

```console
cargo test --locked -p other --example cloud
```

See the [Kubernetes operator chapter](../../src/other/cloud/kubernetes.md) for the disposable-cluster workflow. The published AWS SDK examples live in [the book workspace](../../../bk/crates/other/README.md).
