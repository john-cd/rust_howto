# Staged Cloud Examples

This package contains the historical Shuttle example. To check it from `later/crates`, run:

```console
cargo test --locked -p other --example cloud
```

The published [Kubernetes operator chapter](../../../bk/src/other/cloud/kubernetes.md) contains the disposable-cluster workflow. The published AWS SDK examples live in [the book workspace](../../../bk/crates/other/README.md).
