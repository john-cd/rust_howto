# Crate Coverage Review

Registry snapshot taken November 18, 2026. Each row compares the leading
recently downloaded crates in a [crates.io category](https://crates.io/category_slugs)
with a choice for the staged book. Downloads include transitive use and depend
on how projects tag their crates. Treat them as a discovery signal alongside
the reader task, native prerequisites, and the examples we can run.

The registry query used `/api/v1/crates?category=<slug>&sort=recent-downloads&per_page=5`
for recently downloaded entries and `sort=downloads&per_page=1` for the leader
by total downloads. The table shows the three recent leaders and the all-time
leader for each comparison. For editorial
groups without an equivalent registry category, it uses an adjacent category
and states the limit. Aerospace and Cryptocurrencies remain deferred.
